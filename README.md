# Глюки vs Кореша

2D lane defense в браузере. Вована и Димона накрыло: сидели, смотрели телек, на заднем дворе загремело — вышли, а там зомби-сосед и прочие галлюцинации. Ставь на поле ожившую бытовуху и держись, пока не отпустит.

## Запуск

Игра живёт на GitHub Pages (Settings → Pages → Deploy from a branch → корень ветки). Локально — открой `index.html` в браузере. Сборка и зависимости не нужны.

## Как играть

- Тапни карточку, потом клетку. Лампочки («проблески») — валюта: падают с потолка и варятся чайником.
- Веник убирает поставленный предмет.
- У корешей по умению: Вован орёт (оглушает и отбрасывает всех), Димон кидает тапок судьбы в самого жирного глюка.
- В каждом ряду один робот-пылесос на крайний случай. Если глюк дошёл до крыльца — вас накрыло.
- Клавиши: `1`–`7` карточки, `Q`/`W` умения, `Esc` пауза.

5 ночей, на пятой приходит Кракен, после неё открывается бесконечный режим.

|---|---|---|---|
| Чайник | варит проблески | Зомби-сосед | базовый |
| | | Гитлер в пачке | покрепче, крутит фуэте |
| Кот | плюётся шерстью | Пришелец | быстрый и хилый |
| Холодос | стена | Колобок | очень быстрый |

| Телек | двойной залп | Кракен | босс |

## Модельки и анимация

Кореша и глюки — куклы с костями. `tools/puppets.py` режет собранную фигуру с листа на голову, торс, плечи, предплечья, бёдра, голени и стопы по размеченным суставам; в покое кукла совпадает с рисунком пиксель в пиксель.

Анимация в `puppet.js` построена по двум скилам (spine-animation-ai и svg-character-animation):

- **Ключевые кадры с безье-кривыми** (пресеты Spine: ease, in, out, bounce, fast) вместо синусоид.
- **Ритмы:** покой 2.0 с, шаг 0.8 с (передняя нога прямая на контакте, задняя согнута, руки против ног, подскок таза), атака-укус 0.6 с «замах → удар → доводка», радость как прыжок «присед → толчок → полёт → приземление», крик и бросок — такты с удержанием позы.
- **Голова отстаёт от корпуса** примерно на 0.1 с, крупные кости двигаются сильнее мелких, циклы возвращаются в исходную позу.
- **Пружины поверх ключей:** плавные переходы между клипами, захлёст, отдача от попаданий.
- **Лица подменяются** с листов эмоций: моргание, замах, укус, жевание, боль, оглушение, исчезновение. `tools/puppet_faces.py` подгоняет масштаб и сдвиг лица по совпадению силуэта с головой куклы.

Руки вырезаны из цельной фигуры, поэтому машут в небольших пределах: на больших углах срез становится виден.

## Телефон

Канвас занимает весь экран. В портретной ориентации игра разворачивается на 90°, поворачивать телефон не обязательно. На тач-экранах лампочки собираются сами через несколько секунд.

## Арт

- `python3 tools/sprites.py` достаёт готовые спрайты с листов в `assets/sprites/` (глюки целиком, чайник, холодос, дошик, пылесос, эффекты, фон двора, обложка).
- Глюки с артом — бумажные куклы целиком: покачиваются при ходьбе и делают выпады при укусе. Кот, вентилятор, микроволновка, телек и поздние глюки пока векторные.

- `docs/PROMPTS.md` — стиль и все промты для генерации персонажей, окружения, катсцен и UI.
- Сгенерированные листы клади в `assets/raw/` под именами из промтов.
- `python3 tools/slice.py assets/raw/zombie.png` вырезает хромакей и режет лист на части в `assets/parts/zombie/` (нужны Pillow и numpy).
