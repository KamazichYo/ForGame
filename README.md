# Глюки vs Кореша

2D lane defense в браузере. Вована и Димона накрыло: сидели, смотрели телек, на заднем дворе загремело — вышли, а там зомби-сосед и прочие галлюцинации. Ставь на поле ожившую бытовуху и держись, пока не отпустит.

## Запуск

Игра живёт на GitHub Pages (Settings → Pages → Deploy from a branch → корень ветки). Локально — открой `index.html` в браузере. Сборка и зависимости не нужны.

## Как играть

- Тапни карточку, потом клетку. Лампочки («проблески») — валюта: падают с потолка и варятся чайником.
- Веник убирает поставленный предмет.
- У корешей по умению: Вован орёт (оглушает и отбрасывает всех), Димон кидает тапок судьбы в самого жирного глюка.
- В каждом ряду один робот-пылесос на крайний случай. Если глюк дошёл до крыльца — вас накрыло.
- Клавиши: `1`–`7` карточки, `Q`/`W` умения, `Esc` пауза.

5 ночей, на пятой приходит Кракен, после неё открывается бесконечный режим.

| Оборона | Что делает | Глюк | Особенность |
|---|---|---|---|
| Чайник | варит проблески | Зомби-сосед | базовый |
| | | Гитлер в пачке | покрепче, крутит фуэте |
| Кот | плюётся шерстью | Пришелец | быстрый и хилый |
| Холодос | стена | Колобок | очень быстрый |
| Дошик | мина, греется 9 с | Пьяный пират | шатается между рядами |
| Вентилятор | морозит и замедляет | Иисус | один раз воскресает |
| Микроволновка | взрыв 3×3 | Дракула | лечится, пока жрёт |
| Телек | двойной залп | Кракен | босс |

## Замена векторной графики спрайтами

Персонажи-гуманоиды собраны из частей: `head`, `body`, `arm`, `leg` (рука и нога рисуются дважды — передняя и задняя). Анимация крутит части вокруг суставов, так что достаточно подложить картинки:

```js
GlyukiSprites.load('hitler', {
  head: 'assets/hitler/head.png',
  body: 'assets/hitler/body.png',
  arm:  'assets/hitler/arm.png',
  leg:  'assets/hitler/leg.png'
}, 0.5 /* масштаб */);
```

Правила для PNG (прозрачный фон, персонаж смотрит влево, кореша тоже — игра их зеркалит):

- `arm`, `leg` — висят вертикально вниз, сустав (плечо/бедро) в верхней точке по центру;
- `head` — шея в нижней точке по центру;
- `body` — таз в нижней точке по центру.

Id персонажей: `zombie`, `hitler`, `alien`, `pirate`, `jesus`, `dracula`, `vovan`, `dimon`. Части, для которых картинки нет, остаются векторными. Колобок, Кракен и предметы обороны рисуются отдельными функциями в `EDRAW`/`DDRAW` в `game.js`.

## Арт

- `docs/PROMPTS.md` — стиль и все промты для генерации персонажей, окружения, катсцен и UI.
- Сгенерированные листы клади в `assets/raw/` под именами из промтов.
- `python3 tools/slice.py assets/raw/zombie.png` вырезает хромакей и режет лист на части в `assets/parts/zombie/` (нужны Pillow и numpy).
